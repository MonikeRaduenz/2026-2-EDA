1. Faça um programa que leia continuamente os caracteres (, ) ou 0. Quando os 
caracteres ( ou ) forem lidos, o algoritmo deve validar se até o momento os 
parênteses estão balanceados ou não, exibindo true caso positivo ou false caso 
negativo. Quando for lido o caractere 0, o programa exibir o resultado final 
considerando toda a expressão e finalizar a execução.<br>
Exemplo: dado (()(())), a saída deve ser true

2. Faça um programa que leia um conjunto de números inteiros de tamanho n e armazene  estes valores em uma pilha estática. Em seguida, o programa deve mover todos os dados da pilha estática para uma pilha dinâmica. Ao final, o programa deve exibir os dados da pilha dinâmica na mesma ordem de inserção dos dados inicialmente na pilha estática
