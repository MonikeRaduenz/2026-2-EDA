1. Faça um programa que leia um conjunto de números inteiros de tamanho n e armazene 
estes valores em uma fila estática. Em seguida, deve ser exibido todos os valores do 
conjunto na mesma ordem da sequência de inserção.<br>
Exemplo: dado [10,15,3,7], a saída deve ser 10, 15, 3, 7<p>
2. Faça um programa que leia caracteres continuamente, sempre um a um e até que uma 
quantidade limite de caracteres seja alcançada. Em seguida, o programa deve exibir 
todos os caracteres lidos exatamente na ordem que foram informados ao programa.<p>
3. Faça um programa que leia um conjunto de números inteiros de tamanho n e armazene 
estes valores em uma fila estática. Em seguida, o programa deve ler um novo valor k e 
retornar true caso k exista na fila, caso contrário false.<br>
Exemplo: dados os valores [1,2,3,4,5]e k = 3, a saída esperada é true
