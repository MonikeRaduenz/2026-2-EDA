1. Faça um programa que leia um conjunto de números inteiros de tamanho n e armazene 
estes valores em uma pilha estática. Em seguida, deve ser exibido todos os valores do 
conjunto em ordem inversa à sequência inserção.<br>
Exemplo: dado [10,15,3,7], a saída deve ser 7, 6, 15, 10

2. Faça um programa que leia uma palavra e retorne true se a palavra é um palíndromo, 
caso contrário false.<br>
Exemplo 1: dado a palavra ARARA, a saída esperada é true<br>
Exemplo 2: dado a palavra AMOR, a saída esperada é false

3. Faça um programa que leia um conjunto de números inteiros de tamanho n e armazene 
estes valores em uma pilha estática. Em seguida, o programa deve ler um novo valor k
e retornar true caso k exista na pilha, caso contrário false.<br>
Exemplo: dados os valores [1,2,3,4,5]e k = 3, a saída esperada é true
